# 🚀 YOLO + Centroid Tracker with Noise Filter

سیستم ردیابی اشیاء با **YOLOv8** و **Centroid Tracker** به همراه **فیلتر نویز پیشرفته** و **ذخیره ویدیوی خروجی**.

---

## ✨ ویژگی‌ها

- ✅ تشخیص اشیاء با YOLOv8
- ✅ ردیابی با Distance Centroid Tracker
- ✅ فیلتر نویز (NMS، اندازه، نسبت ابعاد، حذف مرزی)
- ✅ ذخیره خودکار ویدیوی خروجی (`output_video.mp4`)
- ✅ نمایش همزمان در پنجره matplotlib
- ✅ نمایش پنل اطلاعات با تعداد اشیاء و IDها
